Custom WooCommerce Tabs – Rename & Rearrange with Ease

== Description ==
Plin Tabs is a versatile WooCommerce plugin that lets you effortlessly customize your product page tabs. With Plin Tabs, you can add new custom tabs, rename the default Description and Reviews tabs, and reorder all tabs to best suit your store’s needs.

**Key Features:**
- **Add Custom Tabs:** Easily add new tabs to your product pages. Each custom tab requires a name and an optional priority value, which determines its position relative to other tabs.
- **Rename Default Tabs:** Change the titles of the default WooCommerce tabs such as Description and Reviews. This allows you to better align your store's language and branding.
- **Reorder Tabs:** Adjust the display order of all product tabs by assigning priority values. Lower numbers appear first.
- **User-Friendly Interface:** Manage all settings through a dedicated admin menu in WordPress. The intuitive form interface makes adding or modifying tabs simple.
- **Form Validation:** The plugin uses jQuery to ensure all required fields (e.g., tab names) are filled out before saving, preventing accidental submission of incomplete data.
- **Safe and Secure:** Uses WordPress nonces for secure form submission and sanitizes all user inputs to protect your site.

**How to Use:**
1. **Access the Plugin Settings:**
   - Navigate to the "Plin Tabs" menu in your WordPress admin dashboard.
2. **Modify Default Tabs:**
   - Update the **Name** and **Priority** fields for the Description and Reviews tabs. These fields control the label and display order of these default tabs.
3. **Add Custom Tabs:**
   - Click the **Add New Tab** button to append a new input group.
   - Fill in the **Name** for the new tab (this field is required) and specify a **Priority** value. If the priority is left blank, the plugin will automatically assign a higher priority number.
4. **Save Your Settings:**
   - Click the **Save** button to update the settings. If any required field is empty, a validation message will appear, prompting you to complete the field.
5. **View Changes on the Front-End:**
   - Once saved, the product pages will reflect the new tab arrangement. Custom tabs will display with your defined titles and positions, and default tabs will be renamed and reordered according to your settings.

Enhance your WooCommerce store’s product page layout with Plin Tabs and create a more engaging shopping experience by tailoring the information display to your brand’s unique style.


== Frequently Asked Questions ==
**Q: How do I add a new custom tab?**  
A: After installing and activating the plugin, navigate to the "Plin Tabs" menu in your WordPress admin dashboard and click on "Add New Tab." Then, enter the tab name and assign a priority (optional).

**Q: How do I rename the default Description and Reviews tabs?**  
A: You can rename these tabs directly from the plugin settings page by updating the **Name** fields for the Description and Reviews tabs.

**Q: What if I leave the priority field blank for a custom tab?**  
A: If the priority field is left blank, the plugin will automatically assign a higher priority value to ensure that the new tab appears in the correct order.

**Q: Are the changes reflected immediately on the product pages?**  
A: Yes, once you save the settings, the changes will be applied immediately to your WooCommerce product pages.
